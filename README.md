# 감성 다이어리

하루를 기록하고, 원할 때만 AI에게 요약을 부탁하는 모바일 일기장입니다. 계정마다 일기가 나뉩니다.

## 실행

```bash
cd diary-app
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다. 처음에는 계정을 만든 뒤 들어갑니다. 화면은 휴대폰 너비에 맞춰져 있습니다.

## 환경 변수

`.env.example`을 `.env.local`로 복사합니다.

| 변수 | 설명 |
| --- | --- |
| `OPENAI_API_KEY` | LLM API 키. 비어 있으면 AI는 연결되지 않은 상태로 동작합니다. |
| `OPENAI_BASE_URL` | OpenAI 호환 Chat Completions 주소. 기본값은 `https://api.openai.com/v1` |
| `OPENAI_MODEL` | 모델 이름. 기본값은 `gpt-4o-mini` |
| `SESSION_SECRET` | 로그인 쿠키 서명. 비어 있으면 `data/session.secret`에 만듭니다. |
| `S3_ENDPOINT` | S3 호환 주소. 버킷, 키와 함께 있을 때만 사진이 그곳으로 갑니다. |
| `S3_BUCKET` | 버킷 이름 |
| `S3_REGION` | 리전. 기본값은 `auto` |
| `S3_ACCESS_KEY` | 저장소 액세스 키 |
| `S3_SECRET_KEY` | 저장소 시크릿 키 |

키는 서버 요청에만 쓰이고 브라우저 코드에 포함되지 않습니다. S3 값이 하나라도 없으면 사진은 이 컴퓨터에 남고, 클라우드에 저장된 것처럼 표시하지 않습니다.

## 데이터

일기, 사진, AI 응답은 `diary-app/data`에 저장됩니다. 이 폴더는 git에 올리지 않습니다. 다른 계정으로는 일기를 볼 수 없습니다. 이 서버에 접속할 수 있는 사람과 비밀번호를 나누면 그 계정은 열 수 있으니 개인 컴퓨터에서 실행하세요.

계정이 없던 시절의 기록은 처음 만든 계정으로 옮겨집니다.

## AI

- 요약, 감정, 공감, 회고 질문, 월간 회고는 버튼을 눌렀을 때만 실행됩니다.
- 같은 일기 내용의 결과가 있으면 저장된 응답을 다시 보여 주고 API를 다시 호출하지 않습니다.
- 키가 없으면 오류를 안내합니다. 테스트 예시는 화면에서 따로 열며, 실제 분석이 아니라고 표시됩니다. 키 없이 실제 문장을 만들지 않습니다.
- 본문이 있는 기록이 3편보다 적으면 월간 회고를 추측해서 만들지 않습니다.
- 사진은 ‘사진을 AI에 함께 보내기’를 켠 실제 요청에서만 전달됩니다. 테스트 예시는 사진을 보지 않습니다. 2MB 이하, 최대 2장입니다.

## 알림과 설치

계정 화면에서 알림 시각을 고르면, 일기장을 열어 둔 동안 그 시각에 브라우저 알림을 띄웁니다. 앱을 닫은 뒤 도착하는 휴대폰 푸시는 아닙니다.

브라우저에서 홈 화면에 추가하면 앱처럼 열 수 있습니다. 앱스토어용 서명 파일은 개발자 계정 없이는 만들지 않습니다.

일기 내려받기는 계정 화면에서 내 기록과 사진을 zip으로 받습니다.
